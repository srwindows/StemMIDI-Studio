# Contribuir a StemMIDI Studio

Se agradecen propuestas de codigo, documentacion y fallos reproducibles.

Antes de enviar una contribucion:

1. Documenta el sistema operativo, la version, los pasos, el resultado
   esperado y el resultado observado.
2. Nunca incluyas canciones MIDI/KAR, bases Roland, grabaciones, proyectos,
   modelos IA ajenos sin licencia o corpus de entrenamiento personales.
3. Ejecuta la comprobacion de sintaxis de Python y los tests aplicables.
4. Concede prioridad a compatibilidad con Debian 13 y a no romper las
   funciones existentes de las ventanas flotantes.
5. Mantén una sola fuente de verdad para motor, pestañas y ajustes.
6. Documenta la procedencia y licencia de nuevos recursos externos.

**Licencia actual:** PolyForm Noncommercial 1.0.0. La participacion no
convierte automaticamente el proyecto en MIT/GPL.
